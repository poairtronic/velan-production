### Differences from `5.1-structure-decisions.md`
- **`bom_lines`** (`engineering`): **Remove** — replaced by `parameters` + `checklists` + `operations` + `process_templates` master-data hierarchy.
- **`tolerance_revisions`, `tolerance_rules`** (`engineering`): **Replace** with `sc_product_dynamic_values` (per SC product + operation + parameter numeric min/max/target entered by Designer) and static expected values on `parameters`.

## 3. Constraints

- **Primary Keys:** `UUID` on all tables (`shedlock` uses `VARCHAR(64)` `name` PK).
- **Foreign Keys:** `ON DELETE RESTRICT` by default; purge executes in explicit child-to-parent order.
- **Unique Keys:** `users(login)`, `users(employee_id)`, `roles(name)`, `products(LOWER(TRIM(name)))`, `parameters(code)`, `sc_headers(sc_number)`, `pieces(serial_number)`, `sc_product_dynamic_values(sc_product_id, operation_id, parameter_id)`, `operator_values(piece_operation_id, parameter_id)`, `files(storage_key)`.
- **Check Constraints:**
  - `sc_products`: `quantity BETWEEN 1 AND 150`.
  - `sc_product_dynamic_values`: `min_value IS NULL OR max_value IS NULL OR min_value <= max_value`.
  - `operator_values`:
    - `status IN ('DRAFT', 'DOUBLE_CHECK', 'SUBMITTED')`
    - Exactly one typed value column set (when non-null): `(CASE WHEN val_numeric IS NOT NULL THEN 1 ELSE 0 END + CASE WHEN val_bool IS NOT NULL THEN 1 ELSE 0 END + CASE WHEN val_text IS NOT NULL THEN 1 ELSE 0 END + CASE WHEN val_option_id IS NOT NULL THEN 1 ELSE 0 END + CASE WHEN val_file_id IS NOT NULL THEN 1 ELSE 0 END) <= 1`
    - `status <> 'SUBMITTED' OR (submitted_by IS NOT NULL AND submitted_at IS NOT NULL)`

## 5. Volume Estimate & Index Plan

- **Max active volume per PO (100 SCs × 8 products × 150 pieces):** 120,000 `pieces`; × 18 ops = 2,160,000 `piece_operations`; × 15 params = 32,400,000 `operator_values` (mitigated by per-SC archive & purge).
- **Index Plan:**
  - `sc_headers(po_id)` — PO detail SC list
  - `sc_products(sc_id)`, `sc_products(product_id)` — SC product intake & template check
  - `pieces(sc_id, status)`, `pieces(sc_product_id)` — worklist & auto `Packed`/`Delivered` derivation
  - `piece_operations(piece_id, status)`, `piece_operations(sc_id)` — operator queue & purge
  - `operator_values(piece_operation_id)`, `operator_values(sc_id)` — draft/submit lookup & purge
  - `sc_product_dynamic_values(sc_product_id, operation_id)` — Designer Excel & operator limit lookup
  - `outbox_events(status, next_retry_at)` — ECR outbox poller
