## 2. Endpoint Contract: `POST /api/v1/auth/login`

- **Access:** Public (`permitAll()` in `SecurityConfig`).
- **Request (`LoginRequest`):**
  ```json
  {
    "login": "string (required, @NotBlank)",
    "password": "string (required, @NotBlank)"
  }
  ```
- **Responses:**
  - **`200 OK` (`AuthTokenResponse`):**
    ```json
    {
      "accessToken": "<hs256-jwt>",
      "refreshToken": "<hs256-jwt>",
      "tokenType": "Bearer",
      "expiresInSeconds": 3600,
      "accessTokenExpiresAt": "2026-11-28T11:00:00Z",
      "user": {
        "id": "<uuid>",
        "employeeCode": "EMP-001",
        "name": "Full Name",
        "roles": ["OPERATOR"],
        "mustChangePassword": false
      }
    }
    ```
  - **`400 Bad Request` (`ERR_VALIDATION`):** Missing or blank `login` or `password`.
  - **`401 Unauthorized` (`ERR_UNAUTHORIZED`):** Generic `"Invalid credentials"` for all auth failures (unknown user, malformed login, wrong password, password > 72 UTF-8 bytes, inactive account, locked account).
  - **`429 Too Many Requests` (`ERR_RATE_LIMITED` + `Retry-After` header):** Per-IP 1-minute login rate limit exceeded.

## 3. Login Algorithm Summary (`AuthService.login`)

1. Normalise `login` (`trim().toLowerCase(Locale.ROOT)`). If it does not match `^[A-Za-z0-9._-]{3,64}$`, treat as unknown user (`auditLogin = "[invalid-format]"`).
2. Look up user by `LOWER(login)`.
3. Always perform **exactly one** `PasswordEncoder.matches(...)` comparison (using a startup-generated dummy BCrypt hash when the user is unknown or the password exceeds 72 UTF-8 bytes — never truncating and never throwing).
4. If user is inactive or actively locked (`locked_until > now`), fail without modifying counters or `locked_until`.
5. If an expired lock is present (`locked_until <= now`), reset `failed_login_count = 0` and `locked_until = NULL` before evaluating the attempt.
6. On wrong password, atomically increment `failed_login_count` via `UPDATE ... RETURNING`, setting `locked_until = now + duration` when `failed_login_count` reaches `maxAttempts`. `AuthService.login` returns `LoginResult.Failure` so the transaction commits before `AuthController` throws `UnauthorizedException` (`401`).
7. On success, reset lockout counters, issue access + refresh JWTs via `JwtService`, insert hashed (`SHA-256`) refresh token into `refresh_tokens` with a new `family_id`, and return `LoginResult.Success`.

- **Password-change gate (`PasswordChangeGateFilter`):** Authenticated users with `must_change_password = true` may call only `POST /api/v1/auth/change-password`, `POST /api/v1/auth/logout`, `POST /api/v1/auth/refresh`, and `GET /api/v1/auth/me`. All other requests return `403 ERR_PASSWORD_CHANGE_REQUIRED`.
