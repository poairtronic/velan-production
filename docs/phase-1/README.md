## Status conventions
- Confirmed: explicitly stated in the revised requirement source or latest business clarification.
- Proposed: recommendation, not yet approved.
- Open: requires business or technical confirmation.

## Important notes
- The recommended technology stack is not frozen; the source development plan says final choices were not conclusively selected.
- Exact RM/ECR API field names must be taken from their actual contracts. The PDF's integration field list is a proposed business mapping, not a verified API schema.
- The latest clarification controls where older drafts conflict. Packing and dispatch are separate; only actual dispatch confirmation marks Delivered.
- `skills.md` is newly authored project guidance, not a file extracted from an existing source repository.
