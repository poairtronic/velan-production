3. **V018 Note (8.5) — Auth & lockout columns:** `users` lacks `failed_login_count`, `locked_until`, and `must_change_password`; `refresh_tokens` table does not exist yet (needed in Phase 9).
4. **V018 Note (8.6) — Audit columns:** Separate `old_value`, `new_value`, `reason`, `ip_address` columns are not in `V001`; `AuditService` stores them in `details` JSONB.
