# Phase 8 — Owner Decisions (final, from Po)

D1 Login identifier: Employee Code / Username.
D2 Credential: password for all roles, BCrypt.
D3 Tokens: access 1h, refresh 12h.
D4 Lockout: 15 min after 5 failed attempts; force password change on first login and after reset.
D5 Permission order: Admin per-user override first, then role grant; explicit deny wins; no grant = deny.
   Section scope: user with rows in user_sections sees only those sections; no rows = all sections.
D6 Errors: envelope with code, message (English), fieldErrors[], correlationId.
D7 Audit: all state changes, approvals, overrides, cancellations, security events; old_value/new_value JSONB.
D8 Cache: roles, role_permissions, departments, sections, operations, machines; TTL 10 min; evict on update. Never cache piece/operation/quantity state.
D9 Files: drawings/docs PDF, PNG, JPG, XLSX max 25 MB; signatures/images PNG, JPG max 5 MB; archive packs ZIP/PDF max 50 MB; stored by UUID key.
D10 Time: store UTC; API ISO-8601 UTC; display IST (Asia/Kolkata) in UI and reports.
D11 Environments: staging auto-deploys on push to main after CI passes; prod needs manual approval.
