## 2. In-Memory Cache (`shared.cache`)

- **Approved Caches (`CacheNames`):** `roles`, `rolePermissions`, `departments`, `sections`, `operations`, `machines`.
- **Defaults (`app.cache`):** `default-ttl: PT10M`, `default-max-size: 1000`, `allowNullValues: false`, `recordStats: true`, per-cache overrides via `app.cache.specs.<name>.ttl` / `max-size`.
- **Applied:** `RolePermissionGrantCache.findPermissionsByRoleId(UUID roleId)` is cached in `rolePermissions` keyed by `roleId` (never by `userId`).
- **Intentionally NOT Cached:** `user_roles`, `users.active`, `user_permission_overrides`, `user_sections`, and all production-state tables (`pieces`, `piece_operations`, `operator_values`, `measurement_values`, quantities).
- **Single-Instance Note:** Caffeine eviction (`CacheInvalidator`) is per-JVM instance (single Render instance assumed).
