## 2. Error Code & Advice Mapping Table

| Error Code | HTTP Status | Trigger |
|---|---|---|
| `ERR_VALIDATION` | `400` | `ValidationException`, `MethodArgumentNotValidException`, `ConstraintViolationException`, `HttpMessageNotReadableException`, `MethodArgumentTypeMismatchException`, `MissingServletRequestParameterException`, SQLSTATE `23514` |
| `ERR_NOT_FOUND` | `404` | `NotFoundException`, `NoResourceFoundException` |
| `ERR_UNSUPPORTED` | `405` / `415` | `HttpRequestMethodNotSupportedException`, `HttpMediaTypeNotSupportedException` |
| `ERR_CONFLICT` | `409` | `ConflictException`, SQLSTATE `23505`/`23503`, `operator_values_immutable_guard` trigger |
| `ERR_BUSINESS_RULE` | `422` | `BusinessRuleException` |
| `ERR_IDEMPOTENCY` | `409` | `IdempotencyService` different-hash reuse or in-progress key |
| `ERR_INTERNAL` | `500` | Any unhandled `Exception` (generic message, no stack trace/SQL) |
